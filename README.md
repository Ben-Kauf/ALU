# Overview
Combinational Logic implementation of an ALU using VHDL. Designed to be integrated into a CPU design.

## Files
* ECE501HW2.vhd: Contains the combinational logic for the ALU.
* test_ECE501HW2.vhd: Contains a test bench to test the ALU design in ModelSim.
* ECE501HW2.tcl: A .tcl script to automate ModelSim simulation.
